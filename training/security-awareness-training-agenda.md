# Security Awareness Training Agenda — Financial Sector

## Session Overview

| Time | Topic |
|------|-------|
| 09:00 – 09:15 | Welcome, introduction, and importance of security awareness |
| 09:15 – 09:45 | Cyber threats in finance: phishing, ransomware, insider threats |
| 09:45 – 10:15 | Recognizing and preventing phishing attacks |
| 10:15 – 10:30 | Break |
| 10:30 – 11:00 | Protecting customer data: privacy, GDPR, PCI DSS |
| 11:00 – 11:30 | Secure online banking and transaction practices |
| 11:30 – 12:00 | Social engineering awareness |
| 12:00 – 13:00 | Lunch |
| 13:00 – 13:30 | Mobile device security in financial services |
| 13:30 – 14:00 | Password hygiene and multi-factor authentication |
| 14:00 – 14:30 | Incident reporting: how and when to escalate |
| 14:30 – 15:00 | Q&A, assessment quiz, and closing remarks |

## Learning Objectives

By the end of this training, participants will be able to:

1. Identify common cyber threats targeting financial institutions
2. Recognize phishing and social engineering attempts
3. Apply secure practices for handling customer data
4. Use strong authentication and safe browsing habits
5. Report security incidents promptly to the SOC or IT team

## Delivery Methods

- Instructor-led sessions (in-person or virtual)
- Simulated phishing campaigns (quarterly)
- Micro-learning modules (monthly email tips)
- Annual refresher with updated threat landscape

## Assessment

- Post-training quiz (minimum 80% pass rate)
- Phishing simulation click-rate tracking (target: below 5%)
- Training completion tracked in HR/LMS system
