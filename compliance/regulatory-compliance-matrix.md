# Regulatory Compliance Matrix

## Overview

Mapping of key security controls to applicable regulatory and industry frameworks for financial and enterprise environments.

## Framework Alignment

| Control Domain | ISO 27001 | NIST CSF | PCI DSS | GDPR |
|----------------|-----------|----------|---------|------|
| Access Control | A.9 | PR.AC | Req 7, 8 | Art. 32 |
| Cryptography | A.10 | PR.DS | Req 3, 4 | Art. 32 |

## Compliance Activities

### Gap Assessment

1. Select target framework(s)
2. Map existing controls to framework requirements
3. Identify gaps and assign remediation owners
4. Track progress to audit readiness

### Evidence Collection

- Policy and procedure documentation
- Access review records
- Vulnerability scan reports
- Penetration test results
- Incident response logs
- Training completion records
- Change management tickets

### Audit Readiness Checklist

- [ ] Information Security Policy approved and published
- [ ] Risk assessment completed within last 12 months
- [ ] Access reviews performed quarterly
- [ ] Vulnerability scans run monthly; critical findings remediated
- [ ] Incident response plan tested annually
- [ ] Security awareness training delivered to all staff
- [ ] Third-party risk assessments completed for critical vendors
- [ ] Data processing agreements in place for GDPR-relevant processors

## Continuous Compliance

Integrate compliance monitoring into daily operations:

- Automated control testing via GRC platform
- SIEM use cases for control validation (e.g., failed login thresholds)
- Dashboard reporting for management and auditors
