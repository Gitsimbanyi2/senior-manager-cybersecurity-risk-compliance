# Cyber Security, Risk Assessment & Compliance Portfolio

## Overview

This repository demonstrates enterprise cybersecurity leadership, risk assessment methodologies, regulatory compliance frameworks, security operations, and governance practices for financial and public-sector environments.

The portfolio showcases documentation, playbooks, and implementation approaches for building and maturing security programs at the senior management level.

## Areas Covered

* Cyber Security Strategy & Governance
* Enterprise Risk Assessment
* Regulatory & Framework Compliance
* Security Operations (SOC)
* Incident Response & Threat Detection
* Security Awareness & Training
* Audit & Assurance
* Third-Party & Vendor Risk

## Frameworks & Standards

* ISO/IEC 27001 — Information Security Management
* NIST Cybersecurity Framework (CSF)
* PCI DSS — Payment Card Industry Data Security
* GDPR — Data Protection & Privacy
* COBIT — IT Governance
* CIS Controls — Security Best Practices

## Technologies & Tools

* SIEM: Wazuh, FortiSIEM, Splunk
* Vulnerability Assessment & Penetration Testing (VAPT)
* Endpoint Detection & Response (EDR)
* Identity & Access Management (IAM)
* Firewall & Network Security
* Log Management & Threat Hunting (Hayabusa, Sigma rules)

## Repository Structure

### risk-assessment

Enterprise risk identification, analysis, treatment, and reporting.

### compliance

Regulatory mapping, control assessments, and audit readiness documentation.

### security-operations

SOC playbooks, detection rules, incident response procedures, and monitoring guides.

### governance

Security policies, standards, roles & responsibilities, and program maturity models.

### frameworks

Framework alignment matrices, control catalogs, and compliance checklists.

### training

Security awareness programs, training agendas, and workforce enablement materials.

## Key Competencies

| Domain | Capabilities |
|--------|-------------|
| Leadership | Security program strategy, board reporting, budget planning |
| Risk | Risk registers, heat maps, treatment plans, business impact analysis |
| Compliance | Gap assessments, remediation tracking, audit coordination |
| Operations | SOC design, use-case development, alert tuning, playbook automation |
| Assurance | Internal audits, VAPT coordination, control validation |
