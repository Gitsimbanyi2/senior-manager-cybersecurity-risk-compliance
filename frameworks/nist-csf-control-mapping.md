# NIST Cybersecurity Framework — Control Mapping

## Framework Functions

### Identify (ID)

| Category | Activities |
|----------|-----------|
| Asset Management | Inventory hardware, software, and data assets |
| Business Environment | Document mission, stakeholders, and dependencies |
| Governance | Establish security policies and roles |
| Risk Assessment | Identify and evaluate threats and vulnerabilities |
| Risk Management Strategy | Define risk tolerance and treatment approach |
| Supply Chain | Assess third-party security posture |

### Protect (PR)

| Category | Activities |
|----------|-----------|
| Identity Management | IAM, MFA, privileged access management |
| Awareness & Training | Security awareness program |
| Data Security | Encryption, data classification, DLP |
| Protective Technology | Firewalls, EDR, network segmentation |

### Detect (DE)

| Category | Activities |
|----------|-----------|
| Anomalies & Events | SIEM correlation, baseline monitoring |
| Security Continuous Monitoring | Log aggregation, threat intelligence feeds |
| Detection Processes | Defined alert triage and escalation procedures |

### Respond (RS)

| Category | Activities |
|----------|-----------|
| Response Planning | Documented and tested IR plan |
| Communications | Internal and external notification procedures |
| Analysis | Forensic investigation capabilities |
| Mitigation | Containment and eradication actions |
| Improvements | Post-incident lessons learned |

### Recover (RC)

| Category | Activities |
|----------|-----------|
| Recovery Planning | BCP/DRP with defined RTO/RPO |
| Improvements | Update plans based on incident outcomes |
| Communications | Stakeholder updates during recovery |

## Maturity Targets

| Function | Current | Target (12 months) |
|----------|---------|-------------------|
| Identify | Tier 2 | Tier 3 |
| Protect | Tier 2 | Tier 3 |
| Detect | Tier 2 | Tier 4 |
| Respond | Tier 2 | Tier 3 |
| Recover | Tier 1 | Tier 3 |

*Tier 1 = Partial, Tier 2 = Risk Informed, Tier 3 = Repeatable, Tier 4 = Adaptive*
